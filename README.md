# MáquinaPro — GitHub Pages

Versão estática para GitHub Pages. Não usa PHP nem MySQL.

- `index.html`: site principal
- `admin/login.html`: login de demonstração
- `admin/admin.html`: painel de demonstração
- Frota e comunicados: localStorage do navegador
- WhatsApp: configurado em `script.js`

Importante: o login desta versão é apenas uma demonstração e não deve ser usado para proteger dados reais.
